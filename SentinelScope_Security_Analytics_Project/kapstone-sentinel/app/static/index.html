BASELINE MODEL

Evaluation methodology

How the reported metrics are produced.

  • DatasetIncluded synthetic cybersecurity logs labeled normal / suspicious.
  • Split75% training and 25% held-out testing, stratified by label.
  • Text featuresTF-IDF word unigrams and bigrams.
  • ClassifierLogistic Regression with balanced class weights.
  • EvaluationAccuracy, precision, recall, F1, and confusion matrix.

Important limitations

Interpret results in context.

Not production validated

Synthetic data is useful for demonstrating the pipeline, not for proving operational detection performance.

Human review required

A suspicious label is a triage signal, not proof of compromise. Confirm alerts using original logs and context.

Compliance is indicative

Control mappings are starting points, not an audit opinion or certification.

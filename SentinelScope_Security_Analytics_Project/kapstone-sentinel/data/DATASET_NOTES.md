# Dataset notes

`training_logs.csv` contains 480 synthetic event records created for this assessment prototype: 240 labeled `normal` and 240 labeled `suspicious`. The data was generated from illustrative templates, not collected from real people, devices, or organizations. The sample dataset is intended to make the full training and evaluation workflow reproducible. It is not representative of real-world class balance or adversarial behavior.

`sample_logs.json` is a small curated set for dashboard demonstration, including a few related events for correlation. All IPs are documentation/private-range examples.
